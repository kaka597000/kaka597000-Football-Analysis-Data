## 数据与时点

每场用 `xG − npxG` 表示点球相关 xG，并与对手的 `xGA − npxGA` 交叉核对。八个输入须为有限非负数，双方镜像差异各在 `0.002` 以内。球队特征取预测日前最近 12 场已归档比赛，按当时联赛均值中心化，收缩后截在 `±0.75`。同日的比赛一起进入后续历史，球队无法匹配或没有有效记录时使用零对比值。这些字段衡量点球相关 xG 暴露，无法给出判罚次数、罚球人或当场点球概率。[独立信号审计](verification/independent/audit_signal.json) · [审计脚本](verification/independent/audit_signal.py)
