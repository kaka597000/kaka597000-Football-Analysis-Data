**本轮关键数据质量结论**

1. The Odds API的机构盘口可以实际获取，但欧国联返回两条奥地利同时间比赛（对冰岛／对爱尔兰）。两行先隔离，不能将27行返回值整体称为真实已核赛程。scores返回35赛事行，其中仅8条已完赛且有比分，27条是未来／未完赛。
2. InferSports先前的401本轮未重现，赛程与受保护赔率请求均200。但4场C级比赛同时被放进UEFANLA、UEFANLC且event ID不同，不能按别名直接划入A级模型。
3. InferSports荷兰—希腊响应顶层stale=false仍不代表各报价新鲜。按项目现有60分钟门槛，47条报价只有2条亚洲让球满足open、有效价格和时效；6条1X2、21条大小球均不合格。最接近的大小球已64.3分钟。因此本次没有验证出可直接替代The Odds的新鲜大小球备用。
4. BSD欧冠样本返回xG2.57–1.83及xg_estimated=false、确认首发和事件，但仅为单场供应商返回证据，不代表20赛事已有完整且独立认证的原生xG。赔率缺机构／盘口归属，不能当实盘。OpenFoot的2.30–0.65是derived xG；fair odds是模型基准，不是机构报价，不能混作原生xG或实盘。
5. 5Dollar本轮取得的是一场已完赛比赛的Bet365历史开／关盘，closing没有来源报价时间，不能用抓取时间补齐或当当前盘口。football-data赔率消息明确要求启用Odds-Package；OpenFoot事件403明确为plan_upgrade_required，与两家Cloudflare403原因不同。
6. J1在BSD/OpenFoot/The Odds目录存在，5Dollar目录也有对应条目但本次时间窗无赛程；不能据空数组断言没有权限。日联杯未验证到覆盖，泛亚冠目录也不能直接代替亚冠精英身份。

**对本项目的使用安排**

- 盘口优先候选仍是The Odds API，逐场校验身份、机构、市场、盘线、两边价和来源时间。InferSports保留有条件备用，本轮没有通过新鲜大小球验收。BSD聚合价格、OpenFoot fair odds不能充当同机构结算盘口。
- 赛程／身份／积分榜优先使用已实测football-data范围；5Dollar和OpenFoot作已验证范围的补充。欧国联仍须分A级、C级等阶段，不能直接相信提供方别名。
- 过程／首发／事件可以继续验证BSD；5Dollar作为已有统计／事件备用。xG按原生与派生分别保存，缺失伤停保持未知，不能解释为全员健康。
- 日联杯及亚冠阶段缺口继续使用项目已有经核验的公开赛事源补齐；本轮没有为这两项伪造API覆盖，也没有把候选源自动写入数据库或模型。
- API-Football和TheRundown暂列BLOCKED，保留CF-Ray供服务方定位；本次不再重复请求。没有必要因为这两个受阻而停用其他已能提供数据的接口。

**额度、复核与限制**

本轮报告49次API物理调用，另有TheRundown公开网页1次、浏览器导航2次；两家403后均停止API采集。The Odds使用11units，余量287→276；历史赔率可能另计额度，未在剩余3units预算下盲测。5Dollar状态为Community、300次／小时、20次／分钟突发；OpenFoot响应为Starter月额度5000，某次查询显示剩余4979，此值不是最终余额。其余额度按实际响应保留，未猜测套餐或购买订阅。

采集有一项已披露偏差：football-data实际12次超出内部计划10次，最后两次间隔2.118秒低于内部6秒要求；欧冠响应被后续文件写入覆盖，原响应无法复核，故保留丢失说明并将欧冠当前能力记为未验证。没有补造或重请求补盖证据。此缺口不影响其他保留响应的字段核查。

目录映射、时区显示、派生字段及旧文案中的错误均在冻结前校正，记录于root-corrections.json；来源数据及真实quote时间没有改写。原始字节未保留的接口响应以脱敏结构化文件、原始／规范化哈希及说明保存，不能把结构化快照说成原字节备份。
