# 巴甲赛前数据覆盖

本批登记 6 场。11 月 18 日 12:14（北京时间）的首轮监测在 OpenFootball 公开域赛季文件中核对了 6/6 场的巴西比赛日和主客队。该文件没有给出此轮精确开球时刻。开球时间与比赛身份取自赛前留存的 ESPN 记录。Pinnacle 胜平负及大小球同机构报价覆盖 6/6，报价时间和入库时间分别保存。

从每支球队赛前留存的近五场中选取最近一场已完赛巴甲，12 个球队位置对应 9 场不同比赛。ESPN 提供 9/9 场的主客射门及射正。BSD 提供 9/9 场的主客 expected_goals、xg.actual 以及估算标志。其中 3 场有全局估算标记，6 场无该标记。按目标比赛两队均具备此前无全局估算标记的 xG 统计计算为 2/6。两个供应商字段值及各自标记均可单独读取。首轮监测时，两队完整首发覆盖 0/6，六场都还没有进入开球前 90 分钟窗口。后续状态见 [最新覆盖](latest.json)。

每个运行文件保留完整 6 场分母，列出原首版时间点、这次观测、历史过程统计、来源请求、字段质量和临场时间窗。历史数据的本次观测时刻晚于原首冻，训练使用须遵守真实可见时间。临场监测累积每场窗口内首次确认的两份十一人名单，区分已查尚未公布、来源访问失败和窗口内没有采样。常规六小时任务的实际采样覆盖按回执计算。
