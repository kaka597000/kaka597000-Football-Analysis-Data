# 欧洲杯上半场传球接应研究

数据源为 StatsBomb Open Data。研究对象为 2024 年欧洲杯 51 场比赛。分析只使用上半场已发生的传球，考察在已知传球者、起点且传球成功的条件下，能否识别接球的队友。完整事件从官方固定版本下载至本地缓存，发布物保留方法、模型参数、逐场汇总与输入摘要。[开放数据](https://github.com/statsbomb/open-data/tree/4b73468fc5b0f1950f9f66fada70ad3a4f9327cb) · [公开研究使用条款](https://github.com/statsbomb/open-data/blob/4b73468fc5b0f1950f9f66fada70ad3a4f9327cb/LICENSE.pdf)

![StatsBomb](https://raw.githubusercontent.com/hudl/open-data/4b73468fc5b0f1950f9f66fada70ad3a4f9327cb/img/SB%20-%20Icon%20Lockup%20-%20Colour%20positive.png)

| 预测方法 | 接球人首选命中 | 准确率 | 对数损失 |
| --- | ---: | ---: | ---: |
| 传球者对各队友的历史传球次数，加一平滑 | 356 / 1,877 | 18.97% | 2.1765 |
| 直接传球关系、节点统计与场上位置 | 434 / 1,877 | 23.12% | 2.0257 |
| 加入一层有向图邻居信息传递 | 428 / 1,877 | 22.80% | 2.0232 |

6 月 14 日至 26 日的 36 场小组赛用来训练，共 6,161 次有效样本，占上半场常规开放比赛中成功传球的 90.06%。6 月 29 日至 7 月 14 日的 15 场淘汰赛作为整场留出，覆盖 2,529 次同定义传球中的 1,877 次（74.22%）。样本要求明确的传球者和接收者、有效起点和固定的十位候选队友。换人、球员离场等造成传球方最初阵容可用性变化后，后续同队样本继续计入覆盖率分母。

两种训练模型使用相同训练轮数、隐藏层宽度、随机种子和候选队友。每次预测前，图只包含本场该队此前成功的传球。基础特征包括传球两端此前的连接次数、球员传出与接球次数、首发位置类别、已知平均触球位置与本次传球起点。有向图模型再按边上的历史传球次数，聚合传入与传出邻居的特征，用共享权重为候选接球人打分。对照模型屏蔽这些邻居特征。并列时按来源首发阵容内的候选顺序选择。

加入图信息后，留出集接球人首选少中 6 次。按整场比赛进行 2,000 次配对重采样，准确率差的 95% 区间为 −1.18 至 +0.56 个百分点。对数损失略有下降。单场内传球相互依赖，该样本也仅含一届欧洲杯。巴甲、欧国联等赛事的赛前比分、胜平负和总进球收益仍待独立研究。

## 复算

在分析仓库运行以下命令。第一次运行从 StatsBomb 公开仓库按固定提交下载赛程和 51 份事件文件，后续可复用本地缓存。研究脚本仅读取首发和事件，不需要坐标跟踪订阅。

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python runtime/research_program/tactical_graph.py \
  --cache /tmp/statsbomb-pass-euro2024 --out /tmp/statsbomb-pass-euro2024-results
```
