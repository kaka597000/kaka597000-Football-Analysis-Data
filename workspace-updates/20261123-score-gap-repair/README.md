# 20 项赛事的比分误差与修正实验

首选在完整历史主回放中持平。原模型在 5,233 场首选命中 633 场，三选 1,635 场，胜平负 2,695 场。严格大小球全赢为 1,436/2,578。单一联合分布的首选为 614，三选为 1,706。增加首选共识要求后，首选 633，三选 1,705，胜平负 2,746，大小球 1,465/2,578。目标为每项赛事分别达到 20%、40%、65%、70%。主回放四项全过 0/20。

原模型相对固定阶段基线的首选多中 3 场，第二顺位少中 53 场。欧冠 189 场有 130 场首选 1–1，这 130 场中 8 场打出 1–1，全样本中 10 场打出 1–1。2,589 场同机构盘口投影给出的平均首选和三选概率约为 12.2% 和 32.0%。在 266 场比赛中，至少一队在该阶段从未出现，但两队均有同赛事其他阶段的先前战绩。

新的概率模型分别为每项赛事训练。全赛事与阶段进球强度按固定比例结合，此前比赛的真实射门、射正或 xG 按可用性参与。模型用带正则化的联合比分似然训练，先预测整个比赛日再更新。统一分布提供三个互异比分。赛前确有双边报价的方向取市场基准。额外候选仅在两套比分模型和价格模型对首选达成共识、首选占前三概率至少 40% 时更换原首选。

## 验证材料

- 主回放和近期复验沿用已经打开过的 R5 历史窗口。全新收集的早期数据中，两个模型都只用该时期之前的数据训练。世界杯检验 2014 年正赛，自然年联赛用 2017 年，跨年联赛用 2016/17。欧国联、欧协联当时尚未开办。日联杯、亚冠和淘汰赛按可核验的 90 分钟比分纳入。
- 首选共识规则是在看到主回放、近期及初步国内样本后另行登记。原始概率候选、保留旧首选的对照、共识规则各有独立结果。原始及修正前采集口径、比分校验与盘口来源见 sources/ 和 registration/。历史盘口存在报价时点缺失，标为历史代理。
- 192 场真实未来比赛发出了两条新研究轨迹，每条各 192 份首次冻结。未安排比赛的赛事仍保留。活动 Current、Test 和人工 Primary 未切换。
- models/ 按赛事保存逐场预测、数值权重、固定配方刷新、分期以及早期输入。inputs.tar.gz 保存真实过程数据和独立的历史大小球均价。raw-sources.tar.gz.part-* 顺序拼接后按哈希保存新增原件。与 R5 相同的源字节使用 source-index.json 中的 prior 引用。
