# 三臂候选的训练与同场验证

候选以第一比分（联合比分矩阵概率最大的一格）、胜平负及真实盘口大小球为评估目标。三个实验臂分别使用输入矩阵、加入盘口后的矩阵，以及再按赛事校准后的矩阵。每场在三个臂中使用相同的比赛、截点和盘线。正式首冻的有效性和结算另见本次试验的登记及结果。

| 训练、验证步骤 | 可追溯输入 | 对应输出 |
| --- | --- | --- |
| 2025-08-01 开发截点 | 2024/25 五大联赛 1,752 场源比赛中的 1,299 场，复用先前研究按月扩展训练产生的比分强度及实盘收盘价 | season-training-artifact.json |
| 跨赛季同场验证 | 2025/26 同五联赛 1,752 场中的 1,737 场，复用前季保留模型，先预测同日全部比赛再更新历史特征 | season-holdout.jsonl.gz、season-validation.json |
| 2026-11-14 开发截点 | 可在此日前使用的欧洲研究样本与已收到终场回执的真实 Current 首冻 | early-calibration-artifact.json |
| 巴甲同场重放 | 此开发截点之后的首冻，对照原冻结所用的 Pinnacle 胜平负及亚洲总进球报价。开发比较形成于比赛结束后 | frozen-current-holdout.jsonl.gz、frozen-current-validation.json |
| 2026-11-18 00:00 UTC 输入截止 | 合并两季研究资料，加入截止时已获得终场回执的真实 Current 冻结。两类输入各自保留来源计数 | artifact.json |

历史欧洲矩阵来自存档的无盘口进球模型。两季的先前研究均已查看过赛果。欧洲盘口取自 Football-Data 存档中的 Bet365 收盘胜平负和大小 2.5；数据方未给出每笔收盘的报价时间。该部分验证支持研究市场信号的迁移，活动 Current 的实际赛前增益由独立的前向配对试验检验。欧洲研究历史没有可用于首冻校准的 Current，因而第一个开发截点的第三臂沿用第二臂。校准项使用真实首冻的主队零进球、客队零进球、总进球至少四球三个指示量，按赛事向总体估计收缩。

模型以逐场精确比分对数似然估计权重。三个正则化常数为市场混合 2、总体校准 12、赛事校准 30。市场混合权重取值 0 到 1，1 表示矩阵拟合全部去水胜平负与大小球市场约束；市场没有给出精确比分，同一约束条件内的比分形状仍来自输入矩阵。大小球按两侧全赢概率占非走盘概率的比率选边，汇总另列全赢、半赢、走盘、半输与全输。同日分组的 2,000 次配对自助抽样估计净命中率差的区间，少于两个比赛日期时无法估计该区间。

## 复算

在数据仓库根目录执行。使用分析仓库该次提交的 Python 环境，并将 ANALYSIS 指向其本地路径。原始归档来自本数据仓库历史，运行无需访问赔率服务。

```sh
DIR=workspace-updates/20261118-three-arm/training
python "$DIR/prepare_actual_current.py" --data-root . --out "$DIR"
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python "$DIR/fit_driver.py" --source "$ANALYSIS" --data . --out "$DIR"
```

historical-sources.json 保存两个欧洲赛季的来源文件、字段和 SHA-256。actual_current_sources.json 记录实际首冻、原始结果、时间与比赛映射。brazil_retained_inputs.tar.gz 保留恢复所需的巴甲输入，其余实际首冻直接复用数据仓库已有的归档。训练工件的 sample_sha256 覆盖逐场身份、时点、赛果、盘口和输入矩阵字节。
