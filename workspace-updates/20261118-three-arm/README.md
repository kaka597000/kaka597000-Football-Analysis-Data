# 巴甲首选比分、胜平负和大小球前向试验

本批纳入巴西当地 11 月 18 日同一比赛日、北京时间 11 月 19 日早间的六场比赛。名单与评估规则已在训练和出分前提交。主客身份、赛程与场地取自 ESPN，胜平负和亚洲总进球来自 The Odds API 所保留的同机构报价。

| 研究组 | 每场使用的比分分布 |
| --- | --- |
| A · 活动 Current | 原版 Current 的完整主客进球联合概率矩阵 |
| B · 盘口校准 | 用同机构去水后的胜平负概率和真实总进球盘约束 A 的矩阵，保留各盘口约束内的比分形状 |
| C · 盘口与联赛校准 | 在 B 上用历史首冻估计主队零进球、客队零进球和总进球至少四球的偏差，巴甲系数向总体估计收缩 |

三个组分别从矩阵选一个首选比分，并按主胜、平局、客胜的总概率选方向。大小球比较在同一盘口下两边全赢的概率，单列全赢、半赢、走盘、半输、全输。分母与赛果通过同一场的 90 分钟比分核验。另存人工独立研究预测，四场给出首选，两场弃权，与 A 的同场净增单独结算。

## 已有证据

2024/25 赛季的 1,299 场用于拟合开发权重。2025/26 赛季的 1,737 场欧洲开发样本上，比分 Top1 从 208 场升至 225 场，胜平负从 839 场升至 923 场，大小 2.5 全赢从 982 场升至 1,011 场。按比赛日期分组的配对 95% 区间分别为 −0.44 至 +2.36、+2.73 至 +6.89 和 −0.48 至 +3.87 个百分点。欧洲输入来自已研究过的历史进球模型和 Bet365 收盘赔率，缺少逐笔报价时间。该阶段没有真实 Current 首冻用于拟合第三组，B 与 C 逐场相同。

两场此前有实际 Current 首冻和同期 Pinnacle 双市场报价的巴甲，赛后按原截点重放，三组首选比分均为 0/2，胜平负均为 1/2，A、B、C 的大小球全赢分别为 2/2、1/2、1/2。冻结的新六场独立评估活动 Current 与两个候选的差异。
