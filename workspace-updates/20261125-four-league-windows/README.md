`data/` 保存两家提供方的完整原始赛历及 56 条逐日覆盖记录。四个赛事目录各自保存首次登记原件及其 SHA-256。`model-evidence/` 保存当时注册表及四项赛事各自的 Current、Test 权重。登记时在本地首单库检查了两个轨道的全部 79 个赛事 ID。其他研究轨的旧预测保留各自的归属。
