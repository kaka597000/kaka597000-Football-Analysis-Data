# 三组泊松基线：固定配方的同场开发对照

本轮只做离线研究，没有修改正式权重、生产选分/发布配置，没有晋级、部署、恢复自动优化、改写历史冻结或合并旧PR。三组仅是本次有终点的诊断，不登记为永久候选。

## 配方、共同分母与时间隔离

复用源码 `783e02ddebd427383dbdd6a9e4b359dc68c13d8b` 的 v2/model.py、training_inputs.py。数据父提交 `bb9326923ce3554e216d32ee7e9c5734cbb9c567`。输入为既有 EPL-history.json，共2,280场，原始字节压缩保存在本目录；输入与源码SHA256见运行前写入的 protocol.json。

旧benchmark基线衰减180天、对手调整365天，旧DC拟合不加时间权重，不能直接作为这次控制实验。本次离线入口保留简单进球比率/8场先验公式，统一365天衰减；第二臂固定ridge=8的对手调整独立泊松；第三臂复用第二臂完全相同的λ，仅以同一训练段、365天权重拟合DC rho。边界沿用[-0.08,0.006]，温度1，不做网格、校准、择优、全历史refit或未来工件注册。攻防估计器本身不同，因此也不能把臂间差异归因于单一“对手”因素。

## 三比分交付与后续取舍

本次Top3是矩阵概率最高的三个不同格子，按概率降序，同概率按主队球数/客队球数排序；第一项就是Top1。此口径是可复现的统计覆盖，不等于已经实现“不同比赛路径”的综合备选选择。

用户长期展示偏好在此登记：以后每场赛前推荐明确一个第一比分，另外两个去重比分分别说明不同比赛路径；复盘Top1、Top3分开，不能把多给两个比分解释成首选能力提高。本轮不改正式选择规则和生产发布配置，也不把旧冻结缺少的备选事后补进去。

建议保留简单比率作参照，对手调整泊松作为下一次有限前瞻对照的优先配方；本轮不给DC额外晋级依据，也不为它新增永久对照。真正开展下一批前须另行锁定未来赛事名单、真实截点、输入/工件身份、三个比分及停止条件；本轮没有生成未来预测或重置在途试验。真实未来锁定三臂共同样本当前**不可用（null）**，不是0次命中；不能拿巴甲六场回填这一缺口。
