2026年11月22日北京时间，五大联赛完成独立xG训练，最近40场完成同场重放，两场未开赛英超完成首版冻结。候选通过常规双模型预测入口输出，活动 Current/Test 仍各自独立。研究运行源码为 `1196b57c1369193e38b9b0c5c05addaf7d270094`。[源码 PR #53](https://github.com/kaka597000/Football-Analysis/pull/53)

## 独立历史比较

五个联赛分别训练。2020/21 至 2022/23 赛季的5,478场真实 Understat xG参与拟合。2023/24 的1,752场用于校准比分单元格，2024/25 的1,752场选择校准强度。保留2025/26 完整赛季1,752场评价，各队的输入只使用目标日期之前的同联赛比赛。历史原始来源没有当时的发布时间。本次实验对照的基线是同样训练、只看近期进失球、比赛间隔和主场优势的统计模型。

| 2025/26 历史留出 | 第一比分 | 三选比分 | 胜平负 | 比分对数损失 |
| --- | ---: | ---: | ---: | ---: |
| 进失球基线 | 190/1,752（10.84%） | 516/1,752（29.45%） | 843/1,752（48.12%） | 2.958 |
| 加入近期真实xG | 196/1,752（11.19%） | 537/1,752（30.65%） | 876/1,752（50.00%） | 2.941 |
| 加入近期xG并校准比分分布 | 201/1,752（11.47%） | 540/1,752（30.82%） | 870/1,752（49.66%） | 2.939 |

按177个比赛日期聚类，进行5,000次配对自助抽样。校准xG相对进失球基线，第一比分净增11场（多中29、少中18），升0.63个百分点，95%区间为 −0.17 至 +1.37 个百分点。三选净增24场，区间为 +0.16 至 +2.61 个百分点。胜平负净增27场，区间为 +0.17 至 +2.94 个百分点。该历史包缺少可核验报价时间的实盘总进球，实盘指标在下面的冻结样本计算。[配对区间](holdout-intervals.json) · [分联赛参数、样本和指标](training/evaluation.json)

## 最近51场中的同场对照

51场完整首版中，40场使用同一套 Current/Test 版本，可用其原工件和当时已留存的近况重放。26场来自五大联赛，使用各自训练的xG参数，另14场来自四个联赛，使用六场xG和进失球的收缩估算。其余11场使用不同的模型路线或赛事阶段，保留在全批分母。实验不回填首版。原 Test 树权重与融合系数均取自真实冻结所引用的工件。实盘大小球的分母剔除2场走盘，只把全赢计入分子。

| 同样40场 | 第一比分 | 三选比分 | 胜平负 | 实盘大小球严格全赢 |
| --- | ---: | ---: | ---: | ---: |
| 原综合首版 | 4/40 | 11/40 | 18/40 | 23/38 |
| 原 Test | 6/40 | 9/40 | 16/40 | 22/38 |
| 更新 Test 六场近况，输出研究方向 | 6/40 | 9/40 | 18/40 | 25/38 |
| 两路各半融合，允许替换三选 | 5/40 | 9/40 | 17/40 | 22/38 |
| 只重排原综合三选，沿用原方向和盘口 | 5/40 | 11/40 | 18/40 | 23/38 |

研究方向按实盘剔除走盘后的全赢概率选边，原 Test 按既有结算规则选边，因此更新近况一行的大小球变化同时包含选边规则的影响。综合三选内重排把首选2–1从11次减至3次。它改对曼城对富勒姆和摩纳哥对欧塞尔，改错科莫对卡利亚里，净多中1场。三选内重排在看过整套替换的重放结果后单独登记。因为候选集合固定，它保住了原三选的11个命中，也继承了原来的覆盖缺口。40场中仍有13场实际总进球高于三个候选的最高值，8场低于最低值，4场实际0–0均未覆盖。整套替换的方案也未解决这一点。新候选继续独立研究。[同场指标](latest-summary.json) · [最初实验方案](protocol.json) · [三选内重排登记](rerank-protocol.json)

## 干净环境复算

在同一环境克隆源码和数据两个仓库，源码切换至本页登记的提交。安装源码的 `requirements.txt`、`lightgbm==4.6.0` 和 `scikit-learn==1.8.0`，在本目录执行下列命令。

```shell
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python verify_evidence.py --source /path/to/Football-Analysis
```

程序校验压缩包与185个文件的SHA-256，重新拟合五份模型，逐场比对1,752场历史预测，重放40场原工件并验证两场已冻结的研究预测。原活动模型及历史冻结继续按原身份读取。候选模型独立保存在本目录 `training/`。源码变更以前的回滚点为 `d5645f13de63658af79289bfd118d530e2b4f0f2`，数据归档前的回滚点为 `a2b9f948200696d704524b0806cdd07eec795916`。[证据包](evidence.tar.gz) · [逐文件清单](manifest.json) · [复算程序](verify_evidence.py)
