# 赛前盘口信号与欧国联 Elo 的逐场验证

本轮以 90 分钟的唯一首选比分为第一指标。前三比分、胜平负及实际盘线大小球另行结算。欧洲历史比赛使用赛后下载的收盘档案。巴甲和英超实验在开球前单独登记，每场各轨首版作为未来评价依据。

这组实验参考了 PitchQuant 的多机构共识、盘口路径、亚洲让球、国家队 Elo 和输入敏感性检查思路。这里的模型、参数、逐场预测和结果都由本项目独立产生。[参考仓库固定版本](https://github.com/MENG-COOLMAN/PitchQuant/tree/a631941b21a16675f2b688d4e9e43f0c62696141)

## 在相同欧洲比赛上改变一个输入

单元格依次为首选比分、前三比分、胜平负、大小 2.5 球命中场数。基线保留同一套球队进球强度、Bet365 胜平负和大小球。两季数据都在本项目以前的研究中使用过。

| 模型或输入 | 2025/26 · 1,737 场 | 2026/27 · 481 场 |
| --- | --- | --- |
| 单机构市场基线 | 225 / 582 / 923 / 1,011 | 57 / 164 / 273 / 290 |
| 多机构等权去水 | 222 / 583 / 929 / 1,011 | 56 / 165 / 272 / 290 |
| 多机构按抽水倒数加权 | 222 / 583 / 930 / 1,011 | 55 / 166 / 272 / 290 |
| 加入同机构早期与最新价格变化 | 229 / 587 / 920 / 1,018 | 58 / 162 / 273 / 289 |
| 加入同机构亚洲让球盘 | 219 / 596 / 923 / 1,011 | 59 / 167 / 273 / 290 |

变盘候选在两季各净增 4 次与 1 次首选命中。两个按比赛日分组的 95% 区间均包含零。亚洲让球校准两季前三分别多中 14 场和 3 场，首选方向在两季相反。多机构两组与让球实验在设计上固定总球市场边际。跨机构分歧按每个胜平负方向的去水概率四分位距计算，披露适用机构数和按档结果。历史早期价及收盘价缺少逐笔原始时刻。

## 国家队独立 Elo

用目标日期之前已有的国际赛档案重建国家队 Elo，再按欧国联分级校准得分。2024/25 联赛阶段 155 场，相同主场基线的比分、胜平负、大小 2.5 命中为 14 / 68 / 85，增加 Elo 后为 21 / 92 / 91。一个非正常完赛样本保留冲突证据并剔除。2026 年 11 月另有 52 场保留真实 Current/Test 首版，三轨同场成绩如下。

| 轨道 | 首选比分 | 胜平负 | 标准大/小 2.5 |
| --- | ---: | ---: | ---: |
| Current | 5 | 27 | 33 |
| Test | 6 | 31 | 33 |
| 独立 Elo | 5 | 32 | 30 |

52 场的标准 2.5 由既有比分矩阵统一计算，原首版没有实际盘口大小球选择。Elo 在比赛结束后设计，通过早于目标的评分输入作历史比较。后续只登记正式欧国联已确认的联赛阶段。
