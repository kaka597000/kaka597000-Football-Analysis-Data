# R14 独立旧赛季与同场对照

五联赛 2018/19 全部 1,826 个原测试场次进入计分，1,824 场有非零历史过程特征。2015/16 至 2016/17 单独训练，2017/18 选择比分、胜平负和大小球的调整幅度。每场只读此前来源日历日。辅助数据来自固定版本 Kaggle v4 对 Understat 的归档，比赛时钟无时区和历史发布时刻。输入使用实际防守动作数及传球计数。队名、赛事、日期和主客完成一对一配对后才核对两队过程字段。已知出场但无法配成完整对阵的球队记录仍占最近八场的日历位置，该场过程特征记为缺失。逐场原始赔率与赛果从 R10 签名归档读取。

每列可用分母均为 1,826，唯旧市场对照缺失的两个比分指标分母为零。R14 比 R7 首选新增 6 中、失去 3 中，净增 3 场。以比赛日为单位重采样，命中率差的 95% 区间为 −0.117 至 +0.448 个百分点。德甲净增 2 场，意甲净增 1 场。与同幅度纯 xG 对照相比，R14 少中 1 场，区间为 −0.253 至 +0.118 个百分点。

aggregate.json 包含各联赛的原始分子分母、拟合权重、折间日期、覆盖和配对区间。early-audit.json 与 main-audit.json 单独由逐场选择及原始过程字段复核，覆盖三项现代窗口和旧窗口。代码运行时在内存解析固定 ZIP，仓库内只保留汇总。此前来源哈希和许可证标注在 source.json。

在已安装源码依赖并设置 PYTHONPATH 指向其 runtime 的环境中运行。R10 是数据仓库目录 workspace-updates/20261125-r10-shot-conversion。SOURCE 是源码仓库根目录。

```bash
python -m research_program.territory_early --r10 "$R10" \
  --protocol "$SOURCE/research/20261125-r14/protocol.json" --out "$RUNNER_TEMP/r14-early.json"
python verify_comparisons.py --r10 "$R10" --early-aggregate "$RUNNER_TEMP/r14-early.json" \
  --out "$RUNNER_TEMP/r14-early-audit.json"
```

两条命令均接受 --archive 指向相同的公开 v4 ZIP，并会核验 SHA-256。核验还检查原始比分和过程值变化时球队配对保持一致、历史前缀不受以后比赛影响、PPDA 符号及逐场计分。
