# 五大联赛比分优化与实盘前向验证

2026年11月23日，北京时间。项目阶段目标为首选精确比分20%、每场三个比分40%、胜平负65%、实际盘口大小球全赢70%。无本场赔率时，两个后续历史时段的三选和胜平负同场命中数均有增加。首选尚未证明超过同期市场。活动 Current、Test 与原综合首版继续按原记录评价。

## 45场近期赛果

英超、西甲、德甲、意甲、法甲各9场，联赛当地11月20日至22日完赛。45场都有原始综合首版、赛前已冻结的 Pinnacle 双盘和90分钟赛果。大小球覆盖45场，其中1场走盘。研究方案对已知赛果作逐日回放，45场原综合的数字来自当时的真实首版。

| 方法 | 首选比分 | 三选比分 | 胜平负 | 实际大小球全赢 |
|---|---:|---:|---:|---:|
| 原综合首版 | 5/45 | 10/45 | 25/45 | 25/44 |
| 同时点市场推算 | 5/45 | 10/45 | 25/45 | 23/44 |
| 假设没有本场赔率，使用分项选分 | 5/45 | 10/45 | 25/45 | 26/44 |
| 按本轮实际规则选择数据，有双盘使用市场对照 | 5/45 | 10/45 | 25/45 | 23/44 |

分项方案与市场相比，首选新中2场、失去2场，净增0。三选也新中2场、失去2场。无本场赔率时的大小球按同一条真实盘线判断，较市场新中7场、失去4场。样本只有三个比赛日。总进球至少4球的19场里，原综合、市场和两个无本场赔率的模型均未将最终比分列入三选。35场的真实比分落在原综合名单外，剩余10场中首选命中5场、备选命中5场。

## 跨赛季对照与权重

按联赛分别学习球队的进攻、失球与对手强度。过去比赛的盘口可以补充赛果对球队攻防的信息，选型季较优的球队模型使用80%往场市场隐含进球与20%往场xG。往场xG缺失时使用该场完赛进球。历史半衰期120天，球队岭惩罚3、联赛主客场均值岭惩罚20。当前比赛的盘口和赛后xG均不进入这条球队预测；按全日切分，另做了延迟七天的敏感性检验。

2019/20至2023/24有8,955场。2024/25在1,752场对比分选择规则进行比较。保留六场状态模型的首选，备选采用球队模型排序，得到219个首选和581个三选；同样保留首选、备选也来自六场模型时为219和567。胜平负及实际盘线大小球独立选型，均选择球队模型。另试75%同期市场与25%球队模型，相比分别使用同期市场单独推算，选型季首选225比238，故有合格双盘时采用市场推算。分项选分的想法来自对历史各模型成绩的观察。下表的两个后续时段已被项目检阅。

| 2026/27截至11月8日 | 首选 | 三选 | 胜平负 | 实际2.5盘全赢 |
|---|---:|---:|---:|---:|
| 原六场状态模型 | 55/493 | 142/493 | 246/493 | 280/493 |
| 单用往场盘口与xG的球队模型 | 54/500 | 162/500 | 285/500 | 299/500 |
| 保留原首选，分项选分 | 56/500 | 162/500 | 285/500 | 299/500 |
| 本场市场推算 | 63/500 | 161/500 | 281/500 | 301/500 |

原模型能出预测的493场上，分项选分首选净增0，三选净增19，胜平负净增37，大小球全赢净增15。按比赛日重采样，三选净增的95%区间为＋0.57至＋6.91个百分点，胜平负为＋3.40至＋11.80个百分点。500场总分母下多中的1个首选来自补覆盖的7场。2025/26的1,747场同场比较，后三项净增21、48、32，首选净增0。历史2.5球取自 Bet365 的实际归档盘口，该档案只记录开收盘类别，未提供逐笔报价钟。各季全分母、每场预测、概率损失、零球与大比分 Brier、按日配对区间见下方计算文件。

作为独立来源，也核对了 FiveThirtyEight 旧版 SPI 的赛前预期进球。2022/23两源可比1,752/1,826场，单独使用SPI的首选223中，市场216中，SPI三选602中、市场606中；固定25% SPI与75%市场混合为219和602。2021/22两源可比1,716/1,826场，SPI首选247中，市场244中。这项历史比较使用严格同日期、同赛事、同主客的场次，五大联赛的该预估源止于2023年。原始文件来自 FiveThirtyEight，经 Internet Archive 保存，数据出处、哈希及覆盖率见制品。

## 两组真实赛前对照

- 北京时间11月27日00时至30日00时前的五大联赛完整36场，在11月23日11时10分提前冻结。36场均有首选和两个备选，13场有同机构、同次响应、一小时内的胜平负与大小球双盘，另2场只有合格大小球，21场没有合格大小球。所有赛事仍待完赛。窗口外原三场首版保留。
- 对此前登记的蒙扎、莱万特、布伦特福德三场，另在开球前锁定了香港赛马会官方列出的28个全场精确比分和5个“其他比分”分组。来源为未登录的比赛页面，归档时保留北京时间、页面更新时间、可见价格、原文与页面哈希。单档价格未显示单独更新时间。每场按直接赔率排序，与同页面胜平负和大小球推算的排序对照。蒙扎的两个方法分别首选1–2与1–1，其余两场均首选1–1。这三场独立结算，原首版保持。11月23日11时05分的官方公开波胆列表展示34场，当时可见的最远一行截止于11月26日；以上36场周末赛事在该列表上可核验的直接波胆为0。

## 复算

源码使用提交 `3e0845afc442ae8635811edd4dde74a2360d9039`。把本目录的两个压缩包解到同一目录，再从前一轮的数据包取出 `normalized/closing-proxy-with-xg.jsonl.gz` 和 `training-xg/forward-challenger.json`。逐文件校验表位于各包内的 `MEMBER-SHA256.json`。独立读取源文件、训练、选分和冻结所需的源路径、提交和成员名见 manifest。生产注册表的回滚点仍是开展本轮研究前的活动配置。

```bash
python scripts/train_prior_team_strength.py --source "$HISTORY" --form-artifact "$INCUMBENT" --protocol "$BUNDLE/protocol.json" --cache "$CACHE" --out "$REPLAY"
python scripts/select_prior_score_heads.py --study "$REPLAY" --protocol "$BUNDLE/extension-protocol.json" --out "$HEADS"
python scripts/update_prior_team_strength.py --state "$REPLAY/state.json" --history "$HISTORY" --form-artifact "$INCUMBENT" --heads "$HEADS/selection.json" --team-map "$BUNDLE/study/team-map.json" --update "$BUNDLE/study/updates.json" --out "$UPDATE"
python "$BUNDLE/check_forward.py" "$BUNDLE" "$SOURCE_REPO"
```

`HISTORY` 为解压后的JSONL文件，`INCUMBENT` 为六场状态工件，`BUNDLE` 为本轮解包目录，`SOURCE_REPO` 为源码检出目录。训练、选型和刷新使用各自新的输出目录。完成原登记之后的复核使用已保存的首版和目标赛果证据。三场直接波胆可用包内 review_displayed.py，以比赛身份及原始 ESPN 完赛文件校验同场三个排序。
