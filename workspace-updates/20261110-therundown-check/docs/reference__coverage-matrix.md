# Odds API Coverage by Sportsbook and League

> Compare confirmed league coverage across sportsbooks and prediction markets in TheRundown sports data API.

Use this matrix to compare league coverage in the sports data API across current and prior seasons. Coverage varies by date, event, market, and plan. Check live prices for the events you need.

Cricket coverage is sparse and includes T20, IPL, and selected other competitions. A confirmed league does not guarantee prices for every event or market. Volleyball is not covered.

* **Yes**: Confirmed league coverage, including prior-season coverage when the league is out of season.
* **Review**: Coverage has not yet been confirmed. Missing prices do not establish that a league is unsupported.
* **Not supported**: Confirmed that the league is not supported. No cells currently use this label.

Pinnacle is supported across sports and leagues as it publishes markets.

## Check live coverage

Use `GET /api/v2/sports` and `GET /api/v2/affiliates` to discover current sport and affiliate IDs. Then use `GET /api/v2/sports/{sportID}/markets/{date}` to discover markets for a sport and date, and `GET /api/v2/sports/{sportID}/events/{date}` to inspect the prices on each event.

```bash theme={null}
set -e -o pipefail
curl --fail -sS 'https://therundown.io/api/v2/sports'
curl --fail -sS 'https://therundown.io/api/v2/affiliates'

# Use a sport ID and UTC date from the API.
curl --fail -sS -G "https://therundown.io/api/v2/sports/${SPORT_ID}/markets/${DATE}" \
  -H "X-TheRundown-Key: ${THERUNDOWN_API_KEY}"

# Choose market IDs returned above. Request at most 12 per call.
curl --fail -sS -G "https://therundown.io/api/v2/sports/${SPORT_ID}/events/${DATE}" \
  -H "X-TheRundown-Key: ${THERUNDOWN_API_KEY}" \
  --data-urlencode "market_ids=${MARKET_IDS}" \
  --data-urlencode 'main_line=false' \
  --data-urlencode 'hide_closed=true' \
  | jq '.events[] | {
      event_id,
      affiliate_ids: ([.markets[]?.participants[]?.lines[]?.prices // {}
        | to_entries[]
        | select(.value.price != null and .value.price != 0
            and .value.price != 0.0001 and (.value.closed_at == null or .value.closed_at == ""))
        | .key | tonumber] | unique)
    }'
```

An empty `affiliate_ids` array means that the requested markets had no usable prices for that event in this response. PGA and Formula 1 use `GET /api/v2/sports/{sportID}/futures`; see the [Futures guide](https://docs.therundown.io/guides/futures.md).

See [Sports & Coverage](https://docs.therundown.io/reference/sports.md) for sport IDs and [Sportsbook / Affiliate IDs](https://docs.therundown.io/reference/sportsbooks.md) for the book catalog.
