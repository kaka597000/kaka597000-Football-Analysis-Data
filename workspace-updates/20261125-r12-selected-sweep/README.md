# R12 按赛事验证精选三场的首选全中

R12 专门研究四个阶段共同考核的第五项指标。每个候选沿用 R10 已经冻结的唯一首选及两个有序备选。对照按原首选的模型概率排序；候选只用该赛事较早日期的真实命中校正排序。若当日该赛事不足三场，仍保留逐席命中和席位覆盖。

| 六联赛 2019 年部分 | 1,088 | 184 | 0/184 | 0/184 | 106/767 | 105/767 |
| 亚冠精英新增场次 | 55 | 7 | 0/7 | 0/7 | 3/27 | 3/27 |

主面板历史批次按同一比赛日分组，候选在 750 个日期与赛事组合中换了 99 组入选名单。逐席分母含不足三场的日期。某个备选命中只进入单场三个比分覆盖，整批首选全中需要三个不同比赛的唯一首选全部正确。

北京时间 15:49 在同一批 159 场真实未开赛比赛上另行登记排名。20 项赛事形成 15 个有三场的批次、2 个两场批次及 3 个空批次。与原 R10 比较，9 项的入选集合变化，换入 11 个席位。研究榜和已实际展示的亚冠、欧冠综合榜分别结算。当前前向分母尚待赛果。

在与 R10 相邻的同一数据仓中运行 `python verify.py`，可以从原 R10 首版和较早日期拟合的权重独立重算概率、历史入选名单、已完赛的三场全中、未来 49 个有序席位及原版本引用。源码另有研究复训及前向复盘入口。
