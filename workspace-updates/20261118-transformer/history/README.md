# 五大联赛跨赛季 Transformer 对照

在 2024/25 赛季已归档的 1,299 场上训练单层两头注意力模型，在 2025/26 赛季的 1,737 场逐场评估。每支球队使用目标日期之前最近五场的进失球、主客与有效场次掩码。每场共用去水的 Bet365 胜平负及大小 2.5 盘口、同一历史比分基线和相同队伍顺序。收盘价缺少逐笔观测时间，留出的后一赛季曾用于既往开发比较。此次配方按登记固定，训练和评价样本身份均与上轮一致。[事前登记](../registration/protocol.json)

| 模型 | 唯一第一比分 | 胜平负 | 大小 2.5 全赢 | 比分对数损失 |
| --- | ---: | ---: | ---: | ---: |
| 盘口基线 | 225（12.95%） | 923（53.14%） | 1,011（58.20%） | 2.87494 |
| LightGBM | 229（13.18%） | 926（53.31%） | 1,006（57.92%） | 2.87357 |
| LSTM | 226（13.01%） | 924（53.20%） | 1,006（57.92%） | 2.87457 |
| Transformer | 226（13.01%） | 927（53.37%） | 1,010（58.15%） | 2.87443 |

Transformer 对盘口基线改变了 31 场首选比分，其中 5 场改对、4 场改错，另 22 场改前改后都未命中。按日期为单位进行 2,000 次配对重采样，首选比分净增区间为 −0.27 至 +0.38 个百分点。胜平负改对 9 场、改错 5 场，净增区间为 −0.18 至 +0.69 个百分点；大小球改对 2 场、改错 3 场，区间为 −0.30 至 +0.19 个百分点。

Transformer 与 LightGBM 比，第一比分少 3 场，胜平负多 1 场，大小球多 4 场，三项净增区间均含零。与 LSTM 比，第一比分持平，胜平负多 3 场，大小球多 4 场。与 LSTM 的大小球比较有 4 场改对、0 场改错，日期分组区间为 +0.05 至 +0.48 个百分点。多指标和多模型比较使用逐项区间，这一小组差异仍需要在独立赛季或真实首版中复验。

保持基线、盘口和已拟合权重固定，将每队五场中真实比赛的先后顺序反转，保留左侧填充位置。Transformer 投入实际比分分布的选择有 13 场首选比分变化、9 场胜平负变化、4 场大小球变化。3,474 个队侧输出的原始对数进球率调整平均绝对变化为 0.00472。该诊断测量模型对顺序的敏感性，不能直接估计按原顺序使用数据所产生的净命中增益。

## 复算

在数据仓库根目录运行，SOURCE 指向本轮分析仓库的检出目录。Python 环境需要安装 NumPy、SciPy 和 CPU 版 PyTorch，实际版本见复算回执。默认输入定位至上一轮留存的受验 SHA-256 样本及逐场预测。新输出写入临时目录。

```sh
OUT="$(mktemp -d)"
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python workspace-updates/20261118-transformer/history/run_study.py --source "$SOURCE" --out "$OUT"
```
