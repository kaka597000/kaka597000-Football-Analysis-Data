首选与两个备选必须互异。胜平负按常规时间判定。大小球按观察到的实际盘线结算，整盘走水不计分母，半赢计入分母且不计全赢。2,603场有可用盘线，其中25场走水。每项赛事的盘口覆盖、样本及相同比赛上的市场成绩都可在表格中核对。

每项赛事的四个输出在各自的选型期分别确定。对照包括阶段进球基线、动态球队攻守、盘口约束比分分布、比分格校准、泊松梯度提升以及按赛前胜负强弱和进球预期寻找相似比赛的校准。每个比赛日的结果只用于以后的日期。世界杯按2018、2022、2026三届划分，欧国联按赛事周期划分。欧洲跨年联赛主留出是2025/26，自然年联赛是2025。两个杯赛的全赛程完整性须结合 [赛程覆盖](results/fixture-coverage.json) 核查。

同场市场对照中，首选比分为322对321（2,589场），三选为813对861（2,589场），胜平负为2,187对2,246（4,157场），真实大小球全赢为1,436对1,465（2,578场）。比分市场基线从同一家机构的1X2和大小球价格反解比分分布。逐赛事净增、改对、改错和按比赛日重采样的95%区间见 [同场明细](results/paired.csv)。

欧冠189场里，模型选1–1共130次，实际1–1仅10场。84场实际达到4球或以上，首选给出4球以上仅8场。欧联修正盘口输入后首选由14升至22，大小球由72/144变为52/139，不同机构的实际盘线也会改变全赢和走水。完整修正前后记录见 [输入修正对照](results/input-correction.csv)。

第一版20项选型和数据指纹已于查看主留出前存证。核对原始记录发现，欧冠、欧联、澳超、韩K1的同机构配对标记在导入时漏读。四项修正版仍用各自原选型季和相同算法、固定参数、相同日期重算，研究时已经查看过这段留出。其他16项沿用原始独立结果。历史收盘标签多无机构报价时钟，属于日期隔离历史研究。两个挪超2026年5月29日的比分来源有分歧，近期统计采用Football-Data保存值。

北京时间11月24日至30日的192场已分别保存原研究、修正研究和市场优先对照的首版，三者共用同一批比赛。17项赛事有赛程，另外3项继续记录为空。155场有同机构胜平负和大小球，机构报价时钟与观察时间分别保存。市场优先对照在9场使用已展示的正确比分价格、146场使用同场市场反解比分，其余37场使用已锁定的赛事候选。全部待结算。修正版窗口仅有16个出场位置此前未在该阶段出现，使用该阶段先验。

## 复算与恢复

从本目录读取 [全部文件校验值](manifest.json)、[首版数据和工件指纹](registration/all-20-selection-locks.json)、[修正版指纹](registration/all-20-corrected-input-locks.json) 及 [逐来源索引](evidence/source-index.json)。models 下每项包含规范数据、原始选择、逐场预测、锁定与刷新工件。original 保存四项输入修正前的工件。forward-first-issues.tar.gz 保存三个独立轨的192场首版、收据和注册记录。

使用源码仓库的相同版本与 Python 3.12 执行以下命令。审核程序逐赛事重算历史结果、校验首版收据。未来正式完场证据可以使用 research_program.goal_state_forward 的 --by-competition 逐项结算。

```bash
python -m pip install -r code/requirements.txt lightgbm==4.6.0
python data/workspace-updates/20261123-all-scope-kpi/verify_archive.py --archive data/workspace-updates/20261123-all-scope-kpi --code code
```

模型、研究对照和修正轮次分别保留。源码工作接在PR #57、数据在PR #40之上。活动模型继续使用原发布版本。
