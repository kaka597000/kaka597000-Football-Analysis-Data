## 比分为什么拉开

- 30场实战共106球，首版第一比分合计65球。FotMob赛后xG合计105.60，当前和测试模型赛前均值累计89.07、88.23。实际机会量也明显超过模型均值。
- 实际有14场总进球越过三个比分的上限，2场低于三个比分的下限。首版把1–1排首7次，实际出现2次，首选命中1场。
- 胜平负首版选主胜20场、客胜10场、平局0场。实际有5场平局。全场比分的平局概率与单格1–1继续独立检查。
- 利物浦4–0曼联。曼联第8分钟被罚下一人，利物浦第10和第13分钟已连进两球，全场xG 4.35比0.65，原先1–1的路径在开局就被打破。
- 亚特兰大4–4国米。全场xG 3.10比3.38，两队都创造了大量机会。国米三次领先两球，亚特兰大仍追成平局。首版保留了1–1、0–1，没有覆盖双方连续进球的路径。
- 不来梅4–0汉堡。半场0–0，全场xG仅1.52比1.54。不来梅下半场集中兑现机会，本场比分偏差主要体现在实际进球转化。尤文4–0威尼斯也在半场0–0后连进四球，主队xG为1.84。
- 马赛2–3勒芒。勒芒的4.01 xG高于马赛1.42，马赛主胜信号与实际机会差异明显。特温特2–1威廉二世则相反，威廉二世少一人且仅0.08 xG仍率先进球，首版第三比分覆盖了这个分支。
- 奥斯陆KFUM—布兰的赛前原定开球是00:00，赛后两源均给02:00，比赛ID及球队一致，3–4纳入同一场结算。奥格斯堡—美因茨的FotMob红牌事件属于教练曼努埃尔·鲍姆，球员红牌计数为0。

## 调整决定

- 本轮30场首版共3个第一比分命中，三选命中6场。和上一批排除美职联、无重复的48场合计，第一比分7/78（9.0%），三选19/78（24.4%）。两批实战至少4球共31场，首选至少4球共2场，28场的实际总球超过了三个比分的上限。
