# R22 五联赛精确比分研究

R22 检验一个问题。保留 R7 给每个平局比分的概率，只在主胜和客胜比分内采用 R21 的排序信息，能否提高首选和三选命中率？2025/26 赛季 1,752 场回放中，R22 比 R7 少中 6 个首选、9 个三选。英超两项分别多中 1 场和 2 场。五个联赛的新预测均进入研究轨。[训练前的协议](https://github.com/kaka597000/Football-Analysis/commit/c15f9df) · [模型实现与结果](https://github.com/kaka597000/Football-Analysis/pull/98)

## 四套比分覆盖瓶颈

回放与独立 CSV 按联赛和比赛 ID 双向核对了 2,300 场，逐场比对日期、窗口、实比分和四套有序三选。每个窗口、每个联赛的 R7、市场、R21、R22 及并集共用场数分母。并集按每场任一套命中计一次，是知道赛果后从现有候选中选对的上界。

| 历史窗口 | 四套首选并集 | 四套三选并集 | 四套三选全漏 |
|---|---:|---:|---:|
| 2025/26 赛季 | 259/1,752（14.78%） | 652/1,752（37.21%） | 1,100 场 |
| 随后的 2026/27 样本 | 70/500（14.00%） | 184/500（36.80%） | 316 场 |
| 11 月追加样本 | 7/48（14.58%） | 12/48（25.00%） | 36 场 |

三个窗口的首选和三选并集都低于第一阶段的 20% 和 40% 目标。要争取达到最低阶段并向更高目标推进，须扩大比分候选对实比分的覆盖。在本包目录运行 `python -B reports/build_coverage_bottleneck.py` 可复算英、西、德、意、法五联赛及合计的分母、命中和全漏比分频次。[覆盖瓶颈汇总](reports/coverage-bottleneck.json) · [复算脚本](reports/build_coverage_bottleneck.py) · [独立有序三选](verification/independent/ordered-ranks.csv)
