## 工件与选择

Wyscout 2017/18五大联赛1826场逐球累计终场比分全部与Football-Data赛果匹配，3场半场记录冲突保留在原档，本轮实际训练1823场。训练按比赛时间和进球前落后、持平、领先的状态估计强度；球队基础强度来自此前比赛日。首选使用50%的逐球模型和50%的同机构市场比分矩阵，两项备选从逐球模型排序中补足。胜平负和大小球使用同场市场模型。配方只使用2024/25五大联赛选择，固定后先推送锁定记录，再打开外部赛季的评估。试验规则见 [登记提交](https://github.com/kaka597000/kaka597000-Football-Analysis-Data/commit/01f65877870d1b5a320281db3f0406ff155101c8)，工件及配方见 [锁定提交](https://github.com/kaka597000/kaka597000-Football-Analysis-Data/commit/60a4e2465d4f062ba84bbd4174529cd7e2b53413)。

## 复算

`manifest.json` 索引各文件和包内成员的SHA-256。训练用 `training-and-panels.tar.gz#events/locked-training.jsonl`；`events/events.jsonl` 是同一逐球表增加原始文件哈希和来源URL的版本。完整的源进球标记及零球比赛的原始事件数见 `tagged-goal-events.tar.gz`，原赛事清单和原始来源映射见 `event-matches-and-provenance.tar.gz`。完整逐球源的永久编号、许可归属及版本化GitHub镜像保存在训练包的 `events/source-manifest.json`。原始Wyscout公开数据集作者为Pappalardo等，来源见 [Figshare永久版本](https://doi.org/10.6084/m9.figshare.c.4415000.v5) 与 [Scientific Data论文](https://doi.org/10.1038/s41597-019-0247-7)。

`market-evidence.tar.gz` 保留新实采的盘口，`research-and-freezes.tar.gz` 保留逐场对照、冻结记录和运行脚本。已有五大联赛历史盘口复用本仓库 `20261123-kpi-ranking/round2-market-sources.tar.gz`，已知45场的原始控制量复用 `20261123-team-strength/research-and-freezes.tar.gz`。当源码指向清单中的版本时，可用以下命令重新训练、重做选择并复核所有面板和冻结。

```bash
OPENBLAS_NUM_THREADS=1 python workspace-updates/20261123-goal-state/replay.py --data . --code /path/to/Football-Analysis
```
