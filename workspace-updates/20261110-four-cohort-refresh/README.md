# 四联赛独立刷新与对照验证

完整结果见[研究报告](四联赛刷新与对照验证.md)。181条新增、102场时间留出、8份最终inactive候选；不支持活动模型晋级。

`research-evidence.tar.gz` 包含协议、原始响应、完整矩阵、评价和最终工件、原执行源码、依赖映射、633项测试日志、7086项独立复算及研究复盘冻结。公开存放赛事数据已获用户授权，无密钥。`delivery.json`记录压缩包SHA和源码版本，`evidence-manifest.json`记录冻结前各文件SHA；冻结记录单独在`frozen-review.json`，凭证见`freeze-receipt.json`。

恢复到新目录后先核验清单。旧路径依赖映射在归档的`dependency-manifest.json`，只可恢复缺失且已验证的原路径，不覆盖现有不同内容。最终候选包含全部新增标签，不能拿其回放冒充独立留出成绩。所有研究均非历史as-of、非未来赛前业绩。澳超原元数据字段误名通过追加文件澄清，原输出字节保留。
