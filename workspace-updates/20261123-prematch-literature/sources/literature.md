# 文献、预测时点与本轮采用的方法

| 来源 | 原文实际预测的对象 | 对此次实验的影响 |
|---|---|---|
| Fischer & Heuer | 比较机器学习和泊松方法对比赛进球、分差等分布的预测。表中的 RPS 是概率分布误差。其全季球队特征使用了目标比赛以外的其他赛果 | 采用进球分布作基础，只让此前比赛更新球队实力。[原文](https://arxiv.org/abs/2408.08331) |
| Tsokos 等 | 对比 Bradley–Terry 扩展与分层泊松模型。表 5 中分层泊松对挑战测试集的胜平负准确率为 54.85% | 保留简单概率模型，给复杂方法相同的时序测试。[原文](https://arxiv.org/abs/1807.01623) |
| Izidoro 的巴甲研究 | 表 5 的 LightGBM 测试包含 521 个样本，任务是客胜对主胜或平局。由混淆矩阵可复算 379／521（72.74%） | 本轮胜平负保留三个类别。比分另按三个具体比分计分。[原文](https://repositorio.ufu.br/handle/123456789/46157) |
| Sim2Win | 表 1 的 60.90% 属于 CatBoost 的随机留出三分类。论文也报告了跨赛事验证 | 将线性模型和浅层提升树放在同样的赛前输入、相同测试比赛上比较。[预印本](https://arxiv.org/abs/2607.26061) |
| Berrar、Lopes、Dubitzky | 挑战最初排了 736 场，赛程调整后有 714 场最终评价。比分任务以 RMSE 计，胜平负概率任务以 RPS 计，两个任务有不同的第一名 | 同时检查概率损失、首选比分、三选比分和实际盘线全赢。各项保留自己的分母。[原文](https://doi.org/10.1007/s10994-024-06625-9) |
| SoccerNet GRU | 使用目标比赛 0–90 分钟六段数据，样本排除了平局。全文报告的全场准确率是 80.77% | 目标场中的跑动和技术表现可用于滚球研究。此次赛前输入限定为此前比赛的信息。[原文](https://doi.org/10.1371/journal.pone.0288933) |
| HIGFormer | 采用球员过往比赛和球队关系图。论文称各赛区按时间做 80/20 划分，报告总体结果 52.19%、平局类 24.53%。官方代码的按国别切分依赖输入行顺序 | 在同一 Wyscout 来源上直接检验既往传球网络能否在赛前增加信号。本轮实现的是网络特征消融，完整异质图 Transformer 仍是单独架构。[论文](https://arxiv.org/abs/2507.10626) · [代码](https://github.com/zaxbu/HIGFormer) |
| In-game soccer outcome prediction | 连续时间图根据已发生的动作更新比赛状态。训练目标包括动作预测和赛中结果概率 | 动作准确率在本研究中没有对应的赛前比分分母。[原文](https://doi.org/10.1007/s10994-024-06611-1) |
| We know who wins | 基于目标比赛的传球图和其他事件。论文模型 3 从第 45 分钟的 57.36% 升至第 90 分钟的 83.09% | 时间差本身能解释一部分高准确率。赛前研究只读取目标日之前的比赛。[原文](https://doi.org/10.1186/s40537-025-01203-9) |
| TSW-GAT | 公开元数据确认属于实时比赛预测。此次未独立取得可核实所给两个百分比的全文 | 保留为赛中方法参考。[出版记录](https://doi.org/10.1007/978-3-032-27272-0_10) |
| GAPP、GoalNet、OARNet | 分别研究接球与防守影响、球员评价、视频或跟踪数据中的动作。GAPP 摘要中的 6.4% 是接球任务的 BCE 改善 | 这些标签与胜平负、精确比分的赛前评价口径不同。[GAPP](https://doi.org/10.1109/DSAA65442.2025.11248003) · [GoalNet](https://arxiv.org/abs/2503.09737) · [OARNet](https://doi.org/10.1109/TMM.2024.3387724) |
| 稳狗体育文章目录 | 目录共 173 篇，抽读六篇与临场信息、概率校准和盘口判断有关的文章；代表章节没有可复算的外样本成绩表 | 将报价时点固定为赛前 24 小时和 1 小时，再对同一批比赛进行比较。[文章目录](https://wg.jizhita.cn/book/list.html) |

各条目的原始 URL、获取时间、访问范围和可得校验信息保存在同目录的两个 JSONL 文件中。
