## 市场和传球数据

- 在主回放具备同机构胜平负及大小球的 2,589 场中，新模型与由这两类价格推算的市场比分基准首选分别命中 328、321 场。在 2009/10 同口径的 2,130 场中，两者分别命中 285、301 场。市场推算比分与直接报价的正确比分盘口分开标记。
- 凤凰英超、西甲按同一批 1,900 场、同一训练／校准窗口重放。开球前 24 小时的输入得到首选 241、三选 634、胜平负 1,013；前 1 小时分别为 246、650、1,026。两边都保留无报价比赛，并以球队信息补足。赔率覆盖会随时点变化。[凤凰数据及报价时钟说明](https://github.com/kaka597000/kaka597000-Football-Analysis-Data/tree/a2c680dfe403e48d2745c722eb7f0c036ab8d651/workspace-updates/20261123-phoenix)
- 2017/18 五大联赛的 1,826 场 Wyscout 赛事生成了约 119 万条推断传球。以相邻的同队接球事件构图，从下一个比赛日起使用此前传球信息。737 场时间外样本中，既往传球网络与基础比分模型均命中 88 个首选，三选为 264 对 267，胜平负均为 413，大小球为 421 对 425。定价来自同场真实双方报价。大小球方向按整张比分分布和实际盘线计算。[文献与方法对照](sources/literature.md)

## 参数和预测冻结

每个赛事独立训练。攻防、赛场因素、对手强弱和分主客的评分在整场比赛日结束后更新。线性分支与浅层梯度提升分支共享同一份赛前概率先验，各赛事用训练之后、测试之前的校准期比较混合权重 0、0.25、0.5、0.75、1。总球数达到 9 球及以上的部分保留先验相对概率。亚冠本版历史主回放的初始训练期有 0 场可用，使用先验，前向版本另用实际可得记录重新拟合。[各赛事选定的参数](results/weights.csv)

按真实来源价格和实际盘线结算大小球。四分之一盘口保留全赢、半赢、走盘、半输、全输，表中分母剔除走盘，只有全赢计作命中。冻结了 192 场真实未开赛比赛的新版研究预测，同场 R6 预测和来源已留存独立引用。首次记录及三个有序比分可查。[首次冻结表](results/forward.csv)

## 重放

所需源码版本见本目录 manifest.json。另需数据仓库提交 a2c680dfe403e48d2745c722eb7f0c036ab8d651 中的 workspace-updates/20261123-all-scope-kpi 与 workspace-updates/20261123-score-gap-repair。使用源码的 Python 依赖及 lightgbm==4.6.0。在本目录执行以下命令，其中 PRIOR_UPDATES 指向该数据提交的 workspace-updates 目录。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python verify.py --source "$FOOTBALL_SOURCE" --prior "$PRIOR_UPDATES" --workers 2
```

校验程序从原输入重新训练、计算按比赛日聚类的 1,000 次自助抽样区间，并按首次接收的赛程和报价重现前向选择。需同时复算凤凰时，安装 cryptography，在原试用凭据所在的环境执行相同命令并加上 `--phoenix`。公开仓库存放这部分逐场数据的加密分片。
