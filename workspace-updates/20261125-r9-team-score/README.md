首选相对 R7 净增 0.08 个百分点，按比赛日聚类的 95% 区间为 −0.17 至 +0.37 个百分点。三选净减 0.10 个百分点，区间为 −0.44 至 +0.24。R8 主回放首选 597、三选 1,647，R9 分别多中 40 和 69 场。与纯市场在同场有比分覆盖的 2,589 场对照，R9 首选 330 对 321、三选 879 对 861。与市场同场有胜平负报价的 4,157 场，R9 命中 2,233 对 2,246。[逐场预测、固定全强度对照和工件](replay/artifacts.tar.gz)
