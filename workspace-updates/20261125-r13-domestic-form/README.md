# 国内赛程能否改进洲际赛事的首选比分

R13 用此前本国顶级联赛的进失球和赛程密度调整洲际比赛的比分分布。亚冠精英、欧冠、欧联和欧协联分别训练和选权重。欧洲三项赛事的 2025/26 赛季合计 531 场，首选比分由 R7 的 49 场升到 53 场，正确比分进入前三的场数由 169 降到 167。首选净增的逐日整组抽样 95% 区间为 −0.15 至 +1.70 个百分点。随后 198 场的首选净减 2 场。

欧洲 531 场中，欧冠首选从 15/189 升到 16/189，欧联从 20/189 升到 22/189，欧协联从 14/153 升到 15/153。亚冠延伸样本的首选改对 3 场、改错 1 场，55 场中 3 场有双方国内记录，39 场只有单方，13 场两方均缺。亚冠使用在扩展日历上重拟合的同场 R7 对照。独立大小球分母只包括有实际盘线和明确方向的非走盘记录，全赢计中。九场欧冠的价格来自赛前第一次 R5 冻结，R7 预测也已在赛前签发，R13 在赛后进行历史复算。

阶段目标按各项赛事分别验收。主分析尚无赛事同时达到第一阶段四项门槛。活动模型由原有晋级程序管理。

## 数据与两个国内赛程口径

从 27 个国内联赛代码中获得 20 个联赛的 21,497 场常规时间完赛。原始响应带赛事、数字球队 ID、比分、来源网址和实际采集时间。伊朗、韩国、马来西亚、卡塔尔、阿联酋及乌克兰的请求返回 400，捷克代码没有赛事返回。每次预测最多使用此前 120 天内最近八场国内赛事。洲际赛程按 ESPN 逐场主客 ID 对齐，3,766 场的实际开球日期均已核对。

774 场带联赛附加阶段标记，其中包括奥地利联赛最后阶段、希腊和比利时的联赛分组。主分析纳入所有合格完赛。较窄口径用余下的 20,723 场从头重训，两种输入、每场预测及逐赛事权重都已归档。较窄口径在欧洲 531 场仍首选命中 53 场，三选变成 165 场，大小球 194/381。亚冠延伸 55 场仍首选命中 6 场，三选变为 15 场。两种国内赛程口径沿用相同目标赛事分母。第一次开发运行遇到采集文件更新，归档的两次最终训练均使用固定文件散列。历史来源实际采于赛后，赛前可用性按原比赛日期重建。
